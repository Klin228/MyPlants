# Фотографии для первого экрана лендинга

Положите сюда свои снимки под этими именами:

| Файл | Пропорция кадра | Что на карточке |
| --- | --- | --- |
| `plant-1.jpg` | 3:4, вертикальный | Monstera adansonii, $45.00 |
| `plant-2.jpg` | 1:1, квадрат | Alocasia aurea, $240.00 |
| `plant-3.jpg` | 4:3, горизонтальный | Hoya carnosa, $18.00 |
| `plant-4.jpg` | 3:4, вертикальный | Astrophytum, $62.00 |

Годятся `.jpg`, `.jpeg`, `.png` и `.webp` — расширение выбирается автоматически.

**Пропорция необязательна.** Снимок кадрируется рамкой по центру
(`object-fit: cover`), так же как фотография растения в самом приложении.
Если пропорция сильно другая — обрежется больше, только и всего.

**Размер.** Длинная сторона 1600 пикселей, вес до 300 КБ на файл. Это первый
экран, и он должен открываться быстро. Если снимки прямо с телефона по 4 МБ —
скажите, уменьшу.

**Подписи под карточками** — названия и цены выдуманные, они в
`components/LandingCollage.tsx`. Пришлите настоящие, если хотите свои: подпись
должна отвечать снимку, иначе первый экран врёт в мелочи.

Файлов нет — на карточках рисунки, страница работает как обычно.
